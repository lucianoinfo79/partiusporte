# PP05.8 — Homologação Visual e Operacional da Galeria Pública

## Escopo
Qualificação real com Chromium (desktop 1440×900 e mobile 390×844), sem modificar dados do Atlas.
Valida renderização, ausência de overflow horizontal, cartões publicados, abertura do visualizador,
carregamento da prévia, foco, Escape, sessão real e estado vazio. Produz screenshots e JSON sem tokens.

## Instalação no Windows PowerShell

Extraia o ZIP **dentro de C:\partilprova** (a raiz do ZIP contém `script/` e `docs/`).

```powershell
cd C:\partilprova
python -m pip install playwright
python -m playwright install chromium
```

## Execução

```powershell
python script/pp05_8_browser_qualification.py `
  --gallery-url http://localhost:3001/eventos/evento-oportunidade-teste/fotos `
  --photo-id f2e0ed76-dd93-42b4-9e11-154ac1567804 `
  --session-id 0a29eda3-e2ea-4f9c-9e10-228abda588be
```

Opcional: `--headed` abre o Chromium visivelmente.
Saída: `reports/pp05_8/resultado.json` e PNGs (desktop, mobile, viewer, sessão e estado vazio).
Não envie os screenshots publicamente sem verificar dados exibidos.

## Aprovação manual obrigatória

- [ ] Desktop: cards, espaçamentos, cores, tipografia e contraste aprovados
- [ ] Mobile: layout sem cortes, botões e filtros utilizáveis por toque
- [ ] Tema e identidade visual PartilProva consistentes
- [ ] Visualizador: imagem legível, fechamento, teclado, foco e navegação aprovados
- [ ] Sessão Posto 2 selecionada e fotos coerentes
- [ ] Estado vazio claro e link para remover filtros
- [ ] Prévia protegida, sem original/master exposto
- [ ] Navegadores adicionais (Firefox/Safari) avaliados quando disponíveis

## Pendências de massa de dados

O Atlas tinha apenas uma fotografia pública e nenhum álbum na qualificação anterior.
Não declarar aprovados: filtro de álbum com dados reais, paginação acima de 24 fotos,
setas entre múltiplas fotografias e busca por número de peito sem dado real e flag habilitada.

## Critério de encerramento
Script com zero FAIL + inspeção dos PNGs + checklist manual aprovado + pendências registradas.
O script não substitui revisão humana visual.
