# PP05.9 — Qualificação com Massa de Dados Real

## Princípios
Esta Construction é **somente leitura**. Não cria, publica ou altera fotografias, álbuns,
inscrições, números de peito ou dados do Atlas. Usa apenas os endpoints públicos e
confere que as fotografias retornadas aparecem no HTML do PartilProva.

Os testes que não possuem massa real são marcados `SKIP`, nunca `PASS`.
Um relatório sem falhas, mas com `SKIP`, é **PARTIAL**, não homologação integral.
Nenhuma URL assinada, token, fotografia ou corpo de resposta é gravado.

## Instalação e execução (PowerShell no Windows)
Extraia o ZIP incremental na raiz `C:\partilprova`.

```powershell
cd C:\partilprova
python script/pp05_9_real_data_qualification.py `
  --atlas-url http://localhost:3000 `
  --partilprova-url http://localhost:3001 `
  --event evento-oportunidade-teste `
  --session-id 0a29eda3-e2ea-4f9c-9e10-228abda588be
```

Relatório: `reports\pp05_9_real_data.json`.

Quando houver **álbum público real** e **número de peito confirmado**, repetir com:

```powershell
python script/pp05_9_real_data_qualification.py `
  --atlas-url http://localhost:3000 `
  --partilprova-url http://localhost:3001 `
  --event evento-oportunidade-teste `
  --session-id 0a29eda3-e2ea-4f9c-9e10-228abda588be `
  --album-id UUID_PUBLICO_DO_ALBUM `
  --bib-number NUMERO_REAL
```

Não use placeholders literalmente. Habilitar `PARTILPROVA_ATLAS_PHOTO_BIB_SEARCH=true`
apenas depois de confirmar suporte público e política de privacidade no Atlas.

## Preparação de massa real (somente via fluxo operacional existente)
1. No **Atlas WSL** (`~/projetos/atlas/atlas`), publicar **25 ou mais fotos** na edição
   `evento-oportunidade-teste` usando o fluxo PH01 de revisão/publicação. Não tornar
   públicas fotografias privadas apenas para teste.
2. Associar fotos públicas a pelo menos **2 sessões** e **2 álbuns públicos**,
   incluindo sobreposição e exclusividade para exercitar interseção AND.
3. Garantir um número de peito público com associação confirmada a pelo menos uma
   fotografia, se a política do evento permitir busca por número.
4. Reexecutar o script e PP05.8 (Chromium) para verificar também navegação e paginação
   visualmente. Fotos de teste devem ter autorização de publicação.
5. Registrar no relatório IDs públicos dos álbuns/sessões, contagens e cenários
   aprovados; **não** registrar tokens de prévia ou originais.

## Critério de conclusão
`0 FAIL`, `0 SKIP`, inspeção visual da segunda página, viewer com múltiplas fotos,
filtros combinados e conferência de privacidade. Se alguma capacidade for
intencionalmente desabilitada, documentar a exclusão de escopo em vez de declarar
a qualificação integral.
